TinyMovieCatalog est une application locale de gestion de bibliothèques de films et de séries TV (MKV / MP4 / DivX). Elle propose une interface de type médiathèque, centrée sur les affiches, et fonctionne à 100 % en local, sans authentification.

Fonctionnalités

  • Bibliothèques de films ou de séries TV, scan en arrière-plan avec progression
  • Affichage par vignettes, par genre, par saga, par acteur et vue technique détaillée
  • Fiches détaillées enrichies par TheMovieDB (affiche, synopsis, distribution)
  • Détection des doublons, notes personnelles et journal de la bibliothèque
  • Outils : comparaison, export et import de bibliothèques

Langages et technologies

  • Frontend : JavaScript / TypeScript, Angular 19
  • Backend : Python, FastAPI
  • Base de données : SQLite
  • Analyse vidéo : FFmpeg / ffprobe

Systèmes d'exploitation

  • Windows 10 / Windows 11
  • Linux
  • macOS
